# Video Games Shop (Каталог видеоигр)

Данный проект представляет собой REST-сервис для хранения и управления каталогом видеоигр.
Сервис реализован с использованием Spring Boot и демонстрирует принципы построения многослойной архитектуры, 
обработку HTTP-запросов и использование DTO.

## Технологический стек

- **Java 17** — язык программирования
- **Spring Boot 3.x** — основной фреймворк
- **Spring Web** — создание REST API
- **Maven** — система сборки и управления зависимостями
- **Lombok** — сокращение шаблонного кода (геттеры, сеттеры, конструкторы)
- **Jackson** — сериализация и десериализация JSON
- **Postman** — тестирование API

## Слои приложения

- **Controller** — обрабатывает HTTP-запросы и формирует HTTP-ответы
- **Service** — содержит бизнес-логику приложения
- **Repository** — отвечает за хранение и получение данных
- **DTO** — используется для передачи данных клиенту (GameCatalogResponse, GameFullResponse)
- **Mapper** — преобразует Entity ↔ DTO

Архитектура соответствует принципам разделения ответственности (SRP).

## Модель данных

Основная сущность системы — **Game**.

### Поля:

- `id` — уникальный идентификатор
- `title` — название игры
- `genre` — жанр
- `price` — цена
- `releaseDate` — дата выпуска
- `description` — описание

В текущей версии данные хранятся во временном **in-memory хранилище** (`ArrayList`).

## API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/games` | Получить каталог всех игр |
| GET | `/games?genre={genre}` | Получить игры по жанру |
| GET | `/games/{id}` | Получить детальную информацию об игре |
