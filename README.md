# VideoGamesShop
---
Данный проект является прототипом онлайн магазина по продаже компьютерных игр.
---
Функционал проекта
* Просмотр каталога видеоигр;
* Оформление покупки желаемого товара;
* Просмотр "библиотеки" приобритенных товаров;
---
Реализованные технологии:
* REST API
* DTO
* Mapper
